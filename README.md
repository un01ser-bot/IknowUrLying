# I KNOW YOU ARE LYING

용의자와 자유롭게 대화하며 진술 속 거짓말과 사건의 실마리를 찾아가는 싱글 플레이 추리게임입니다.

- 개인 프로젝트
- 개발 기간 : 2026.07 ~ 개발 중
- Unity / C#
- Elice ML API

## 프로젝트 소개

정해진 선택지를 고르는 방식보다 실제 용의자를 심문하는 듯한 추리 경험을 만들고 싶어 시작한 프로젝트입니다.

플레이어는 3D 공간에서 사건 현장을 조사하고 용의자와 직접 대화하며,
수집한 증거와 진술을 바탕으로 사건을 추리하게 됩니다.

현재 용의자 심문, 증거 수집 및 저장, 조수방에서의 증거 확인 기능까지 구현되어 있습니다.

## 주요 구현

### 용의자 데이터

용의자별 성격, 말투, 피해자와의 관계, 사건 정보를 `SuspectProfile`로 관리합니다.

특히 사건 당일의 실제 행적 `TruthStatement`와
용의자가 처음 주장하는 진술 `ClaimStatement`를 분리하여,
실제 사건과 용의자가 말하는 사건을 서로 다르게 구성할 수 있도록 했습니다.

### 공통 심문 시스템

용의자마다 별도의 심문 기능을 구현하지 않고,
3D NPC가 자신의 `SuspectProfile`을 공통 심문 시스템에 전달하도록 구성했습니다.

전달받은 Profile을 기반으로 용의자 정보와 Prompt를 구성하고,
Elice ML API를 통해 해당 용의자의 응답을 받아 UI에 출력합니다.

### 증거 시스템

증거의 이름, 설명, 발견 장소, 이미지 등의 고정 정보는 `EvidenceData`로 관리하고,
플레이어 진행 데이터에는 수집한 증거 ID를 저장하도록 분리했습니다.

수집한 증거는 조수방에서 다시 확인할 수 있으며,
증거와 관련된 용의자 정보도 함께 확인할 수 있도록 구성했습니다.

## 개발 예정

- 증거와 진술의 모순 활용
- 조수의 수사 노트 및 힌트
- 최종 추리 및 범인 지목
